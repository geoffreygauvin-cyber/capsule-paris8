CAPSULE – site statique (HTML, JavaScript et images)

Pour modifier les textes : voir MODIFIER-LE-SITE.md (tout se fait dans contenu.js).

Contenu :
- index.html  : apparence (CSS) et squelette de la page
- contenu.js  : tous les textes, contacts, horaires, ressources, FAQ
- site.js     : construit la page à partir de contenu.js
- img/        : illustrations

Hébergement : aucun serveur ni base de données. Netlify republie le site à chaque modification sur GitHub.
Police : Poppins est chargée depuis Google Fonts (ligne <link> dans index.html). Pour un hébergement universitaire (RGPD),
la télécharger et l'héberger localement.
Logo : recréation vectorielle (dans site.js), à remplacer par le fichier officiel.
