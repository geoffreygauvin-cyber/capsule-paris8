Accès équipe

Comptes de l’équipe

Un compte par étudiant·e : son nom de compte apparaît comme thérapeute dans les invitations. Le code d’un nouveau compte n’est affiché qu’une fois.

Données sensibles : n’écrivez dans les notes que de l’organisationnel (créneaux, relances), jamais de détails de santé ou de situation personnelle. Supprimez une demande dès qu’elle n’a plus d’utilité.

Cliquez sur un créneau libre (+) pour y placer une personne, ou sur un rendez-vous pour le modifier ou l’annuler. 3 salles, créneaux d’1 h, du lundi au mercredi.
